# AI Reservation Automation

AI-powered reservation and email automation platform for hospitality businesses.

## Status

🚧 Work in progress

## Goal

The goal of this project is to automate the processing of reservation
emails and assist hospitality businesses with faster and more reliable
responses to guests.

## Planned capabilities

- Reservation email processing
- AI-based information extraction
- Reservation data validation
- Business rule processing
- Availability integration
- AI-assisted email responses
- Human approval workflow
- Email automation
- Reporting and monitoring

## Tech Stack

- C#
- .NET
- ASP.NET Core
- PostgreSQL
- Docker
- AI/LLM APIs
